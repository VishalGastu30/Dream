## Problem

Fine-tuning Large Language Models traditionally requires immense computational resources and suffers from reward noise when relying solely on neural reward models. There was a need for a resource-efficient, reliable pipeline for smaller models that guarantees deterministic execution evaluation.

## Constraints

- Computational limitations required using parameter-efficient fine-tuning (QLoRA).
- Need to eliminate reward noise inherent in LLM-as-a-judge approaches.
- Final model must be small enough to run on CPU-only edge devices.

## Key decisions

- Chose GRPO (Group Relative Policy Optimization) over PPO for better stability in resource-constrained environments.
- Replaced neural reward models entirely with deterministic verifiers (a math interpreter and logic classifier) to ensure absolute ground-truth reward signals.
- Elected to quantize the final output to 4-bit GGUF, prioritizing accessibility and edge deployment over marginal precision retention.
