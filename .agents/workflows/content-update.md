# Workflow: content-update

Add or update content → validate → build → preview → merge.
Use this workflow any time content is added or changed in `content/`.

## Steps
1. **Use the `add-content` skill** for the specific entity type (project, experience, cert, etc.).

2. **Run validation**:
   ```bash
   pnpm validate:content
   ```
   Fix every error before proceeding — do not skip or suppress validation failures.

3. **Preview both views**:
   ```bash
   pnpm dev
   ```
   Verify the item appears correctly in:
   - Cinematic view (correct position in timeline/universe)
   - Professional view (card + detail page)
   - Resume Forge (item selectable, correct section)

4. **Check resume page counts** (if a featured project or bullet was added):
   ```bash
   pnpm build:resumes
   ```
   Verify all presets still fit within their `targetPages` limit.

5. **Full check**:
   ```bash
   pnpm check
   ```
   All gates must pass.

6. **Commit** with conventional commit format:
   ```
   content: add <entity-type> <id>
   content: update <entity-type> <id> — <what changed>
   ```

7. **Push branch** → open PR → preview deploy URL generated by CI.

8. **Verify** the preview URL: content appears correctly in both views.

9. **Merge** after CI is green.
