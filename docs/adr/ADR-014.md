# ADR-014 — Domain is optional; start on *.pages.dev

**Status:** Accepted
**Date:** 2026-10-03

## Decision
Launch on the free `*.pages.dev` (or `*.workers.dev`) Cloudflare URL.
`SITE_URL` is an environment variable so a custom domain can be added at any time
without code changes.

## Rationale
- Keeps the ₹0 promise from day one — no domain cost.
- The live URL is functional and shareable from week 1.
- A custom domain can be added instantly by changing one env var and updating:
  - GitHub OAuth callback URL
  - Content-Security-Policy
  - Sitemap

## GitHub Student Developer Pack option
The Student Developer Pack offers a free `.me` domain for one year (renewal is paid).
Use this when the site is ready for wider sharing — before Phase 9 soft launch.
Do NOT buy the domain on day 1; use it as a launch reward.

## Steps to add a custom domain (when ready)
1. Register domain (Student Pack or paid).
2. Set `SITE_URL` env var in Cloudflare dashboard and GitHub Actions secrets.
3. Update GitHub OAuth app callback URL to `https://<domain>/api/auth/callback/github`.
4. Update CSP `connect-src` and `frame-ancestors` in `apps/web/public/_headers`.
5. Update `apps/web/public/robots.txt` Sitemap URL.
6. Redeploy.

## Revisit when
Before submitting to Awwwards or sharing widely — a custom domain looks more professional.
