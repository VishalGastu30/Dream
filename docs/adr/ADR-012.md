# ADR-012 — No custom CMS; optional Keystatic in local/dev-only mode

**Status:** Accepted
**Date:** 2026-10-03

## Decision
No hosted CMS. Keystatic may be used optionally in local/development mode only —
it is not deployed to production. The admin UI needs server routes, which a static export lacks.

## Rationale
- A CMS is another service to maintain, pay for, and keep secure.
- The content schema is simple enough for YAML + a text editor or an agent.
- Keystatic's local mode provides a GUI for editing YAML without running any server in production.

## Constraints
- Keystatic admin UI is NOT deployed — it runs only during local development.
- Content validation still runs through `pnpm validate:content` regardless of the editing tool.

## Rejected alternatives
- **Contentful, Sanity, etc.:** paid services; lock-in; another vendor dashboard.
- **Keystatic cloud mode:** needs server routes, incompatible with `output: 'export'`.

## Revisit when
You want to edit content from a phone or tablet without setting up a dev environment.
Then: Keystatic cloud mode on a branch with server routes — evaluate cost at that point.
