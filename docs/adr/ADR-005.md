# ADR-005 — Better Auth + GitHub OAuth, owner-only allowlist

**Status:** Accepted
**Date:** 2026-10-03

## Decision
Use Better Auth for session management with GitHub as the only OAuth provider.
An allowlist of exactly one GitHub user ID (`OWNER_GITHUB_ID`) is the only way to sign in.
Visitor accounts and sign-ups are permanently disabled.

## Rationale
- Auth.js (NextAuth) is now maintained by the Better Auth team; their README recommends
  new projects start with Better Auth.
- Owner-only = tiny attack surface. No visitor PII in the auth system.
- GitHub OAuth is free and zero infrastructure.
- One numeric user ID in an env var is the entire allow-list — trivial to audit.

## Rejected alternatives
- **Rolling custom auth:** more surface area, JWT handling risks.
- **Clerk, Auth0:** paid plans required for meaningful usage; another vendor.
- **Cloudflare Access:** may require a Cloudflare-managed domain and/or payment info for initial setup.

## Revisit when
You add collaborators or team members who need studio access.
