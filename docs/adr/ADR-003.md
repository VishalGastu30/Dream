# ADR-003 — Content in Git (YAML + MDX) validated by Zod

**Status:** Accepted
**Date:** 2026-10-03

## Decision
All career content lives in `content/` as YAML and MDX files, validated by Zod schemas
in `packages/schema`. Content is the single source of truth. No hosted CMS.

## Rationale
- Versioned and diffable — every change is a commit with a diff.
- Portable — content moves to any host without migration scripts.
- Agent-editable — a schema file tells agents exactly what's valid.
- No CMS to maintain, no SaaS to pay for, no login to manage.
- Build-time validation catches errors before they reach production.

## Rejected alternatives
- **Custom Postgres + admin dashboard:** large surface area for a single editor.
- **Hosted CMS (Contentful, Sanity, etc.):** another vendor with free-tier limits and lock-in.
- **Keystatic (hosted mode):** needs server routes, incompatible with static export.

## Revisit when
You need non-technical editors (e.g. a team member who won't commit YAML).
Then: Keystatic local mode is the first option (ADR-012); hosted CMS is last resort.
