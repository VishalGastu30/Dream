# ADR-004 — D1 only for genuinely dynamic data

**Status:** Accepted
**Date:** 2026-10-03

## Decision
Cloudflare D1 stores only: testimonial invites/submissions, contact inbox messages,
AI usage counters, and Better Auth session tables. Everything else is in Git.

## D1 tables (v1)
| Table | Purpose |
|---|---|
| `testimonial_invites` | One-time invite tokens + metadata |
| `testimonials` | Submitted + moderated testimonials |
| `contact_messages` | Contact form inbox |
| `ai_usage` | Daily request counters for the AI assistant |
| *(Better Auth tables)* | Sessions, accounts (added by Better Auth migrations) |

## Rationale
- Free tier is ample for portfolio traffic (5M reads/day, 100k writes/day).
- Keeps everything in the Cloudflare ecosystem — no cross-vendor queries.
- A committed snapshot (`content/testimonials.snapshot.json`) means the site works even if D1 is down.

## Rejected alternatives
- **Supabase/Postgres:** second vendor, more moving parts, overkill for 3 tables.
- **Full Git-based testimonials:** too manual for the invite-and-moderation workflow.

## Revisit when
Data becomes genuinely relational or exceeds D1 free limits.
