# ADR-007 — GSAP (+ ScrollTrigger, SplitText) and Lenis smooth-scroll

**Status:** Accepted
**Date:** 2026-10-03

## Decision
Use GSAP for all timeline animations, ScrollTrigger for scroll-driven animation,
and SplitText for text reveals. Use Lenis for smooth scrolling.
Native scroll is never hijacked — Lenis smooths it; ScrollTrigger maps scroll progress to animation.

## Rationale
- GSAP is now 100% free including all formerly Club-only plugins (SplitText, ScrollTrigger, etc.).
- GSAP has the best timeline control for complex multi-element scene choreography.
- Lenis is lightweight (~4 kB), composable with GSAP's RAF loop, and respects `prefers-reduced-motion`.

## Key rules
- Always check `window.matchMedia('(prefers-reduced-motion: reduce)')` before playing any GSAP timeline.
- Never lock the scroll position or prevent the user from scrolling away at any point.
- Duration limits: micro 150–200ms, UI 300–450ms, scene 800–1400ms. Nothing > 1.6s that blocks input.

## Rejected alternatives
- **Framer Motion only:** weaker timeline control for complex multi-element choreography.
- **Native Web Animations API only:** no timeline composition, harder to sequence large scenes.

## Revisit when
GSAP licence changes (currently: standard licence, free for all use including commercial).
Track at gsap.com/standard-license/.
