# ADR-011 — Cookieless analytics (Cloudflare Web Analytics)

**Status:** Accepted
**Date:** 2026-10-03

## Decision
Use Cloudflare Web Analytics (or equivalent cookieless solution) for site analytics.
No cookies, no consent banner, no PII collection.

## Rationale
- Fits the "know almost nothing about the visitor" privacy principle.
- No GDPR/cookie consent banner needed → cleaner UI, no modal on first visit.
- Already in the Cloudflare ecosystem — same dashboard, no extra vendor.

## Rejected alternatives
- **Google Analytics:** cookies, consent banner, PII collection, third-party surveillance.
- **Plausible/Umami self-hosted:** not free — requires a server.
- **Plausible/Umami cloud:** another paid service.

## Revisit when
Never — the no-cookie policy is a non-negotiable part of the privacy design (ADR-011).
